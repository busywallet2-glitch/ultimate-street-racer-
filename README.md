# Ultimate Street Racer

A fast, neon-lit arcade racing game that runs directly in a modern web browser. No installation or build step is required.

## Play

Once GitHub Pages is enabled, open:

https://busywallet2-glitch.github.io/ultimate-street-racer-/

You can also run the game locally by opening `index.html` in a modern browser.

## Features

- Responsive browser game for desktop and mobile screens
- Keyboard controls and on-screen touch controls
- Nitro boost with a rechargeable meter
- Four selectable car colors
- Rival racers, collision slowdowns, speed display, lap counter and race timer
- Pause and resume support
- Best-time storage in your browser

## Controls

| Action | Keyboard | Mobile |
| --- | --- | --- |
| Accelerate | W or ↑ | ▲ |
| Brake | S or ↓ | Not currently mapped |
| Steer left | A or ← | ◀ |
| Steer right | D or → | ▶ |
| Nitro | Shift or Space | NITRO |
| Pause / resume | Esc | Use the pause key on a keyboard |

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a current version of Chrome, Edge, Firefox or Safari.
3. Press **Start Race**.

The game is currently a lightweight 2D canvas arcade racer with a perspective road effect. It does not require Node.js packages or external game assets.

## GitHub Pages

The repository includes a GitHub Actions workflow that publishes the root of the repository to GitHub Pages when changes are pushed to `main`. If Pages has not been enabled for this repository yet, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.

## Project status

This is an early playable prototype. Race pacing, opponent behavior, mobile braking, audio, and more advanced track/gameplay features can be improved in future updates.
